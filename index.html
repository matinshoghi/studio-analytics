Studio Analytics

Studio Analytics is a private, internal tool. It reads the YouTube Analytics of channels that we own, so we can see how our own videos perform. It is not offered to the public.

Privacy policy

When a channel owner signs in, the tool asks Google for read-only access to that channel's YouTube data and YouTube Analytics (for example views, watch time, subscribers, traffic sources and audience retention). It cannot upload, edit or delete anything.

The data is kept in our own private files and used only to improve our own videos. We never sell it, share it with anyone, or use it for advertising. Sign-in tokens are stored only on our own computer.

Access can be removed at any time at myaccount.google.com/permissions.

Studio Analytics' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Terms

This tool is for the channel owners' own use only.
